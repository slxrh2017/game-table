# Telegram Game V1 — Vercel Game Room Visual Test Console V3

This package is a Vercel-ready static visual test console built to match the supplied Game Room visual references: dark game-room background, metallic gold/crimson status chrome, bull system identity, player chat bubbles, gold system messages, red-packet collection presentation, and the existing composer.

The developer test drawer is intentionally hidden behind `REAL ENGINE TEST CONTROL`.

IMPORTANT: This package does not contain the actual Node.js Backend 11.16 / Engine executable source. The current File Library material available in this conversation contains architecture/specification documents, not the complete backend source tree. Therefore the included phase buttons are a UI test harness, not a claim that Vercel is executing the real Engine.

To make this a genuinely real-engine Vercel test, upload/provide the latest executable Backend 11.16 + Engine package (including package.json/source/dependencies). Then the server-side portion can be bundled/deployed and the UI can consume its authoritative WebSocket events.

The UI itself is designed around the canonical server-authoritative model: clients render state/events; they do not decide outcomes or authoritative timers.
