# Telegram Game V1 — Game Room Real Engine Test Console

The player-facing portion of this console uses the latest Game Room visual direction:
- charcoal/black base
- metallic gold
- deep crimson
- warm ivory text
- rounded dark chat surfaces
- bull-head emblem in the system/banner presentation

The lower REAL ENGINE TEST CONTROL drawer is developer-only. It is styled with the same visual language but is not part of the player UI.

`bull-logo.svg` is a self-contained bull-head emblem used by this console.

The HTML does not become authoritative. A real browser WebSocket endpoint can be supplied to the test console; the endpoint must connect to the existing canonical Backend/WebSocketGateway and authoritative Engine.
